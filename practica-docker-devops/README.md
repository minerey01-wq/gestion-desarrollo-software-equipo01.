# Control de visitas

Aplicación web desarrollada con Node.js, Express y Redis.

## Requisitos
- Node.js 20
- npm
- Docker
- Docker Compose
- Git

## Instalación
npm install

## Pruebas
npm test

## Ejecutar con Docker
docker compose up --build -d

## Endpoints
- GET / : página principal
- GET /health : estado de la aplicación
- GET /api/visitas : contador de visitas

## Detener servicios
docker compose down
